# 会战地面：恢复卡牌肉鸽原草地

默认「军团会战」使用当前卡牌肉鸽的深绿色草地。源图是 `assets/environments/iberia-grass.png`，只取 (640,160)-(1152,672) 的纯草地，保存为 `iberia-grass-ground.png`。原图边缘的树、岩壁和水域没有带入；战场仍无羊或其他装饰对象。

保持 3200×3200 的纯俯视坐标、原部队大小、地图边界和交互。地面 Sprite2D 保持 scale=1，用 region 扩展覆盖范围；镜像重复使边缘衔接，不把 512 图拉伸成 4096。没有新生图、改色、滤波材质或额外近景噪声。此前黄绿色地面及其 shader 已从主工程移除，备份仅在本机 output。

资源约束：一张 512×512 基图，按 RGBA8 计算约 1 MiB；无 mipmap、无动画，最近邻采样，一层地面、一遍普通纹理取样，不新增逐单位循环或逐帧资源加载。仍有小范围重复纹理，不宣称无限地形无重复。其他远征、山口及攻城场景不变。

验证：Godot 4.7.2 / Apple M4 / Compatibility，1280×720 窗口、960×540 战场渲染，seed 71，原有 14 队/114 士兵，60 FPS 上限、VSync 关闭。经主菜单自动鼠标事件进入会战，检查部署、总览、正常时间开战和暂停画面；80 项回归通过，包括选队、改令、缩放、胜负、重试和场景往返。这是自动输入验证，不是人工实玩。

240 帧部署抽样：p50/p95 16.667/17.517 ms，CPU process 监视器采样 p95 7.579 ms，静态内存 182437187 bytes，纹理占用计数 741377133 bytes。前一黄绿色地面同条件记录 p50/p95 16.666/16.798 ms；短样本有波动，不能证明性能提升或无退化。独立 GPU 时间未取得，目标设备、峰值规模和帧时预算仍未确认，未做完整性能或导出包验收。

已有测试退出音频释放告警（the-pyre.mp3、crusade.mp3）已在未修改 main 基线上复现，属于独立遗留问题。本轮回归未报该告警。
