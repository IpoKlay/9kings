# 新版正式 RTS：冲锋与接战功能验收

按2026-11-10用户纠正，主要验收从主菜单进入当前 StrategyBattle，不再以旧 WhiteboardBattle 性能场景代替新版游戏。停止独立性能专项；只在实际操作受卡顿阻断时定位对应问题。此前性能诊断保留历史记录，不在本轮声称达标或已修好。

## 接入正式战斗的改动

此前双方闪白、局部受击和动作停顿只在独立多排预览里分发。本次 StrategyBattle 显示层观察真实伤害事件：仅伤害>0且明确士兵槽位时记录反馈，重冲锋给命中骑兵及受击者同时闪白；普通受击只作用于被击中的士兵。重冲锋可覆盖最近的轻击反馈，避免冷却窗口吞掉主撞击。该观察不再次结算伤害、不改变脚点和命令，不增加全场暂停或全场震屏。

共用现有呈现助手，不复制另一套动作。白色遮罩改用原生 Image RGB 操作，保留每个像素的alpha；避免首次实际碰撞时在GDScript逐字节改整张图。仅缓存实际用到的图集角色表；重试重建观察器、清除旧角色/命中记录。沿用当前impact设置。战场、资源、城墙、迷雾、部队面板和新主菜单入口保持原样。

## 验证边界

- 输入是引擎事件和真实控件，非系统鼠标人工实玩；截图来自实际渲染窗口。
- 胜利使用敌方城镇HP清零的受控分支，证明UI与重试衔接；没有把它称为自然打完一局。
