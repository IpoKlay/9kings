# 当前原生 RTS 测试玩法 · 2026-11-10

用户本轮明确要求将后续改动放到 main；基于已合并 PR #6 及 main 后续美术/战斗更新继续开发。入口：`godot-game/project.godot` → F5 →「军团会战 · RTS」。本文优先于旧白板和山口操作说明。

## 测试开局与操作

各资源10000；城镇中心、军营、房屋、3块相邻农田、方形城墙和四座城门；5村民、2持盾护卫、2枪兵，人口9/55。四门默认打开，可选中后开关。军事单位立即生产，但仍扣资源、检查人口和出口空间；村民基础生产时间8秒。

- 单击/框选单位，Shift追加；右键移动或交互。选村民显示建筑栏，选建筑显示其生产和科技。费用顺序为食物/木材/铁矿。
- 选生产建筑后右键地面设置集结点。选中时显示金色旗帜与虚线；新单位出生时自动获得移动指令。
- 选单位显示当前指令：普通移动用绿色旗帜/虚线，攻击移动用红色。临时队伍中选择多个成员，只显示离这批成员中心最近的一人的指令标记；不同队伍分别显示。
- 单选单位显示生命、基础伤害、近战/远程护甲、攻击间隔及兵种克制额外伤害。攻击速度数值按“秒/次”解释，值越小越快。阵型、举盾等临时增益另按战斗规则结算。
- H坚守、A自动、X攻击移动、C冲锋、V箭雨。Esc取消选择与待下达指令，不撤销已经执行的采集、建造或行军。
- 中键拖动、滚轮缩放、Tab总览、Space暂停。边缘移镜平滑加减速；士兵常规移动约0.45秒加速至目标速度，并平滑改变移动方向。当前全部兵种（含村民、工程师、攻城器和野狼）的基础移动速度、冲锋速度均为此前的一半。

## 城门通行与多人行军

实体碰撞半径由9小幅增加到10，默认阵位间距由30增加到36。普通行军中，落在城墙或建筑内的阵位会寻找目标附近的可站立位置；城外集结点不会把后排塞回城门口。显式切换阵型仍要求完整阵型能放下。通过拐点时，只有下一段路径无遮挡才会跳过已接近的拐点；单位到位后被友军挤开，会重新回到自己的位置，新军令会取消旧位置。关闭的城门和悬崖仍不可穿越。

绕障图按通行尺寸缓存，建造、拆除和开关门会清空缓存；相连墙段合并用于寻路，短距离碰撞检测只查看附近障碍。

## 阵型

同类型最多21人，按人数多数阵型集结；骑兵、盾兵、枪兵、弓兵按前后顺序排列。楔阵为1/2/3/4/5/6人的实心三角形；散阵间距1.8倍并交错；环阵朝外；密集/龟甲收紧。变阵顶部显示名称和真实5秒模拟进度。枪兵全程处于丘陵时为15秒；未到阵位会显示“正在就位”；战斗或新指令可打断。

## 视野和资源区域

采用64单位网格的黑雾/探索记忆：没探索过全黑；探索过但失去视野的区域变暗，保留地形及上次看见的建筑，不显示活单位，也不能点选、自动锁定隐藏敌军。敌城邦位置开局以标记显示，不提供视野。普通军事单位视野560，村民400，普通建筑280，防御建筑650；初始城墙视野限制在二环内。

四个不画出的区域采用相对城镇的方形距离，以匹配方形城墙：半径448内为一环，448–850为二环，850–1250为三环，其余为四环。地图使用固定种子便于测试复现。

| 区域 | 内容 |
| --- | --- |
| 一环 | 恰好1普通铁矿、3相邻农田、1片9棵树的树林 |
| 二环 | 浆果、羊、树、普通铁矿 |
| 三环 | 鹿、果树、普通铁矿；2处蛮族营地，每处3–8守军 |
| 四环 | 野猪、主动攻击的野狼、大型铁矿；2处蛮族营寨，每处20–25守军、2哨站 |

普通营地清除守军自动领取各资源100。大型营寨清除守军和两哨站后自动领取各资源600，并随机得到5–8名盾兵/枪兵/弓兵/普通骑兵；不含精锐骑兵。营寨守军额外25%生命、20%攻击及2护甲。解救奖励允许暂时超人口，后续生产仍检查上限。野狼死亡后可采集；其他动物目前是静态采集点，狼使用简单像素绘制。

基础每村民每秒收益：农田/树/普通铁矿1，浆果1.1，羊/狼1.3，鹿1.5，野猪1.8，果树食物和木材各0.6；大型铁矿暂定1.5，储量5000。其余自然资源储量1200，农田2500。原经济科技可提高采集效率。

## 城镇科技和兵种

城镇升级与军营五级兵种晋升是独立科技。城镇初始一级，每级基础研究20秒。同类城镇增益按加算累计，新生产单位和新建建筑同样生效，生命升级保持当前生命比例。

| 升级至 | 木/铁 | 本级新增效果 |
| --- | --- | --- |
| 2 | 400/400 | 村民生产速度、生命各+30%；建筑生命+20% |
| 3 | 600/600 | 同上再加一次；村民攻击+5、双护甲+2 |
| 4 | 800/800 | 生产速度、村民生命再+30%，建筑生命再+20%；建筑成本-10%，研究速度+30%，军队移速+10% |
| 5 | 1000/1000 | 解锁精锐骑兵；军队生命+10%；脱战3秒后回复2生命/秒；满血军队伤害+5% |

| 单位 | 生命 | 基础攻击 | 近/远甲 | 间隔(秒) | 食/木/铁 |
| --- | --- | --- | --- | --- | --- |
| 持盾护卫 | 100 | 11 | 5/7 | 1.1 | 200/50/50 |
| 枪兵 | 80 | 15，对骑兵另+10 | 3/3 | 1.4 | 180/0/30 |
| 骑兵 | 120 | 10，对弓兵另+5 | 2/2 | 1.1 | 250/0/80 |
| 弓箭手 | 60 | 10 | 0/0 | 2 | 130/100/0 |
| 精锐骑兵 | 300 | 28，对弓兵另+10 | 6/6 | 1.4 | 400/0/300 |

骑兵冲锋为+100%增伤，与其他增伤加算；克制额外伤害先加到基础攻击，再应用增减伤与护甲。五级满血军队额外+5%增伤也按加算。

AI城邦仍采用时间预算招募与周期出击，开局保护180秒；蛮族和狼拥有独立据点防御/追击行为，不接受旧会战导演的跨地图军令。摧毁敌城镇获胜，自己城镇被毁战败。尚无完整采集型敌方经济AI，未进行长局平衡或Windows实机验证。
