# Yu Ho 的 RTS 玩法分支

分支：`yuho/rts-gameplay-expansion`。基于 main `eb078612`；不向 main 直接推送，也不自动合并。本次修改只改变该分支的独立会战入口；远征与旧场景仍保留。

## 试玩

Godot **4.7.2 stable** 打开 `godot-game/project.godot`，F5 → **军团会战 · RTS**。右侧面板点击开战。初始各资源100，已有城镇、军营、4村民、1工程师和28名军事单位。城镇每20秒消费35食物生产一位村民，人口满或食物不足时等待。

- 单击选一人，Shift加选，拖动框选，Ctrl点选同类型；右键地面移动并集结。Shift左键可沿用原连续路点。
- 集结按骑兵、盾兵、枪兵、弓兵顺序排列。同类型按所选人数最多的阵型重组，每队21人、默认每排7人先补前排。同行最多5队，6至10队分别3+3、4+3、4+4、5+4、5+5，各行居中。更多队伍继续均衡分行。队伍是逻辑分组，每个人保留自己的生命和命令，不合并血量。
- 村民右键资源采集；果树同时产生食物和木材。食物还有浆果、鹿、羊、野猪、牛、鱼、农田。铁矿脉产铁。
- 工程师选中后，从右栏选建筑并点击建造，再点空地。工程师需要实际抵达才能施工；靶场、马厩限制在已完工军营360范围内。全部建筑只消费木材。
- 选择单位种类点击生产；生产消耗食物，并受对应建筑、人口和队列限制。精锐骑兵需晋升四级。
- 军营研究二至五级晋升；每级增加初始基础生命和伤害的10%，近战/远程护甲各+1。已有与新训练同类型单位同步，保持当前生命比例。升级价格逐次翻倍。城镇、房屋、军工厂和学院也有研究，均耗三类资源。学院只能选一次经济或军事方向。
- 阵型面板切换/调整朝向；需要脱战3秒，构建至少5秒且实际走到阵位才生效，期间受击或攻击中断。枪兵在丘陵构建速度降至1/3，骑兵在丘陵攻击增益减30个百分点。悬崖不可通行；河流目前可涉水。
- 默认枪兵加护甲；楔形增冲锋伤害并削弱命中敌人的攻击与攻速；环形增强近战攻防并降速；散阵提高移速、降低范围伤害；龟甲加甲降速，骑兵冲锋可破坏；弓兵密集阵降低普攻、提高箭雨。骑兵楔形冲锋前需对准20度内，使用朝向按钮调整。C冲锋，H坚守。
- 盾兵按钮举盾，以40%攻击损失换60%减伤。弓兵近战使用短剑伤害判定；箭雨点击地面，射程650、落点散布80、冷却12秒。
- 右键敌方建筑攻城。攻城锤只打城门；投石机可远程攻城及对单位造成范围伤害，扭力弩炮为高伤单体远程。步兵右键攻城塔装载（最多21人），再选塔右键敌墙登墙。工程师右键攻城器或己方建筑修复，消耗木材。
- 右键己方城门开关；墙和关闭的城门阻挡寻路，摧毁后重新计算障碍。哨站、堡垒、城墙塔楼自动攻击范围内敌人。
- 守住城镇，击败三波增援并摧毁敌堡获胜；城镇被摧毁失败。暂停与半速沿用原系统，重试清空经济、队伍、研究与建筑状态。

## 规则与调参

`data/balance/strategy.json` 是新增兵种、建筑、成本和阵型参数表。没有由用户指定的成本、时间、基础数值和增益幅度均为首版参数，未宣称完成平衡。

单位直接伤害按 `基础攻击 × (1 + 增伤之和) × max(0, 1 - 减伤之和) - 对应类型护甲`，最终不低于0。晋升先提高基础属性，再计算增益；增伤/减伤分别加算。密集阵的普攻惩罚不作用于箭雨，箭雨加成与其他攻击增益加算。

模块：`scripts/strategy/battle.gd` 复用已有单兵寻路、战斗、动画和投射系统；`formation.gd` 生成集结目标；`interface.gd` 提供经济和阵型操作；`field.gd` 绘制地形与交互对象。原系统新增的钩子只在新模式存在时启用。

## 验证与限制

验证使用 Linux Godot 4.7.2：规则30项、战斗/攻城20项、主菜单鼠标输入与重试检查、30秒实际规则循环；另通过旧版单兵移动17项和冲锋37项。原生 OpenGL 窗口完成菜单、选兵、移动、截图和重试。详见 `VALIDATION.md`。

这是可运行的玩法首版，不是已平衡的完整成品：

- 动物目前是静态可采集像素标记，没有游走、逃跑、反击或狩猎动画。部分建筑、工程师与攻城器复用已有美术，尚无各自专属素材；短剑使用已有弓兵动作。
- 登墙采用单兵墙面通行层，支持装载、登墙及离墙；不是完整的城墙路径网络、楼梯、楼层高度和墙上战斗系统。墙上单位仍以二维地面坐标显示。
- 攻击建筑使用射程、冷却及生命值判定，尚无投石弹落地才扣建筑血量的完整表现时序。单位间投石仍复用已有抛射与范围命中。
- 仅有一张固定资源地图、固定三波敌军，没有地图编辑器资源节点工具或宏观建造AI；未新增局中存档。
- UI目前中文，旧模式保留原有中英文。未做长局经济平衡、千人性能或 Windows 实机验证；没有导出新的 exe。
- 旧白板入口截图/布局测试的预期不再适用于本分支的新默认地图，不能将这些旧预期当作已通过。

下一轮优先人工试玩集结与经济节奏，补专属美术与完整攻城层；所有修改继续留在此个人分支。
