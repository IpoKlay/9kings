# Yu Ho 的 RTS 玩法分支

分支：`yuho/rts-gameplay-expansion`。基于 main `eb078612`；不向 main 直接推送，也不自动合并。本次修改只改变该分支的独立会战入口；远征与旧场景仍保留。

## 试玩（2026-11-10 更新）

Godot **4.7.2 stable** 打开 `godot-game/project.godot`，F5 → **军团会战 · RTS**。进入地图立即开始，取消战前部署、“点击开战”、全军进攻和神力等旧会战操作栏。开局有城镇中心、军营、6名村民，各资源100，没有预置军队。

### 选择决定右栏

- **未选择 / Esc**：右侧没有指令栏；顶部只保留资源、人口、科技、时间、暂停、总览、菜单。Esc 同时取消建造预览、技能瞄准、拖框和选中状态，不暂停游戏，也不撤销已经下达的采集、建造或生产任务。
- **左键村民**：显示建筑图标网格和木材价格。点击建筑图标进入放置，左键空地确认，右键取消放置，Esc 清空所有选择。村民实际走到现场施工；无效位置不扣资源，保留预览供重选。
- **左键城镇中心**：右栏替换为村民生产和城镇研究。必须点击生产图标加入队列；不再自动扣粮生产村民。村民35食物、基础8秒。
- **左键军营 / 靶场 / 马厩 / 军工厂**：只显示该建筑可生产的单位和对应研究。命令绑定当前这座建筑，不会自动转到其他建筑。每座建筑最多5个排队项，支持查看进度和取消退款；人口满时等候，出口被堵时等待空位。
- **左键房屋 / 学院**：显示对应的研究和发展方向选择。研究绑定所选建筑；该建筑被摧毁，研究中止。
- **左键军事单位**：显示坚守、攻击移动、适用技能和阵型。没有建造栏。工程师仍可修复攻城器，普通建筑由村民建造。

### 地图操作

单击选一人，Shift加选，Ctrl点选同类型，普通左拖框选，中键拖动移图，滚轮缩放，Tab总览，空格暂停。左键空地清除选择；右键地面移动并集结，右键敌军攻击。X攻击移动、C冲锋、H坚守、V箭雨（需选中适用兵种）。

村民右键树林、果树、浆果、动物、鱼或铁矿脉采集；果树同时产食物和木材。右键农田采食物。村民右键未完工建筑可接手施工，右键己方建筑修复。靶场和马厩需在已完工军营360范围内。

保留21人集结、每排7人、6–10队均衡分行、兵种前后排序、阵型多数选择、加算伤害和五级晋升。阵型至少构建5秒且实际抵达阵位才生效，进入战斗中断；枪兵在丘陵构建更慢。建造花木材，训练花食物，研究花三类资源。

攻城继续通过右键敌方建筑操作：攻城锤打城门，远程攻城器攻击工事，步兵可装载攻城塔登墙。右键己方城门开关。

### AI 与胜负

敌方有自己的城镇中心和军营。以受限的招募预算随时间生产预备军，开局约180秒首次派兵，此后约95–120秒派遣一批，最多维持30名存活敌军。增援会通过已有单兵战斗AI向玩家推进，不再限制为三波。摧毁敌军军营可阻止继续招募。

摧毁所有敌方城镇中心获胜；己方城镇中心全部被摧毁则失败。无需等候波数，也无需消灭地图上最后一个敌兵。结束后可直接重新开始；所有选择、队列、研究、资源与AI状态重置。

## 规则与调参

`data/balance/strategy.json` 是新增兵种、建筑、成本和阵型参数表。没有由用户指定的成本、时间、基础数值和增益幅度均为首版参数，未宣称完成平衡。

单位直接伤害按 `基础攻击 × (1 + 增伤之和) × max(0, 1 - 减伤之和) - 对应类型护甲`，最终不低于0。晋升先提高基础属性，再计算增益；增伤/减伤分别加算。密集阵的普攻惩罚不作用于箭雨，箭雨加成与其他攻击增益加算。

模块：`scripts/strategy/battle.gd` 复用已有单兵寻路、战斗、动画和投射系统；`formation.gd` 生成集结目标；`interface.gd` 提供经济和阵型操作；`field.gd` 绘制地形与交互对象。原系统新增的钩子只在新模式存在时启用。

## 验证与限制

验证使用 Linux Godot 4.7.2：经济开局23项、上下文鼠标UI27项、规则30项、战斗/攻城20项，以及210秒实际规则循环；另从正常资源开局完成约201秒的采集、生产、三级研究和摧毁敌城镇胜利脚本对局；另通过旧版单兵移动17项和冲锋37项。原生 OpenGL 窗口完成菜单、选兵、移动、截图和重试。详见 `VALIDATION.md`。

这是可运行的玩法首版，不是已平衡的完整成品：

- 动物目前是静态可采集像素标记，没有游走、逃跑、反击或狩猎动画。部分建筑、工程师与攻城器复用已有美术，尚无各自专属素材；短剑使用已有弓兵动作。
- 登墙采用单兵墙面通行层，支持装载、登墙及离墙；不是完整的城墙路径网络、楼梯、楼层高度和墙上战斗系统。墙上单位仍以二维地面坐标显示。
- 攻击建筑使用射程、冷却及生命值判定，尚无投石弹落地才扣建筑血量的完整表现时序。单位间投石仍复用已有抛射与范围命中。
- 仅有一张固定资源地图、持续周期招募AI，没有地图编辑器资源节点工具或完整宏观建造AI；敌方经济为计时预算，不是实际村民采集经济；未新增局中存档。
- UI目前中文，旧模式保留原有中英文。未做长局经济平衡、千人性能或 Windows 实机验证；没有导出新的 exe。
- 旧白板入口截图/布局测试的预期不再适用于本分支的新默认地图，不能将这些旧预期当作已通过。

下一轮优先人工试玩经济与兵力节奏，补专属美术、完整攻城层与实际采集/建造型AI；所有修改继续留在此个人分支。
