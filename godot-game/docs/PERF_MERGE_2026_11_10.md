# 性能分支合并 · 2026-11-10

基于 main `9140099`，合并 `perf/rts-1000-batch` 的 `3af0cbd`。不包含尚未合入的 PR #17。

## 冲突与兼容处理

- 寻路：保留当前 nearby_walls 空间索引、动态城门与障碍更新；在筛出的墙体上使用性能分支的内联线段检测。
- 单兵：保留战争迷雾 can_detect、登墙导航、盾阵回位和已有伤亡/反馈钩子；接入统计、单位索引、脚点/目标范围和邻域缓存。
- 将持久单兵记录放在 rules 的复用数组，避免 unit → row → unit 循环引用破坏阵型规划的深拷贝。已有阵型检查覆盖该路径。
- 绘制冲突优先保留 main 的新版图集、透明阴影、骑兵接触、白闪与冲击反馈。没有使用旧分支替换整个绘制函数；仅调整步态读取以兼容新的 PackedFloat32Array。
- 保留 main 的60Hz决策频率：`simulation_lod=false`。丢弃模拟积压的限步策略保留为显式诊断选项 `bounded_catchup=false`，默认循环不丢弃模拟步。未以慢放或降低决策频率换取本次提速结论。
- 未减少人数、修改移速/伤害、美术资源或游戏分辨率。

## 本机验证

Apple M4、macOS、Godot 4.7.2 stable；原生 OpenGL Compatibility 窗口渲染1280×720。无窗口检查仅作逻辑诊断，不作为真实帧率测量。

18套相关脚本通过，共1118项显式计数检查（另含不输出检查计数的寻路负载脚本）。覆盖经济规则、战斗、阵型/镜头、63人过门、城门窗口、导航负载、八边形墙/迷雾/血条/施工、经济扩展、个人移动/冲锋、骑兵遮挡、冲击白闪、死亡、攻击建立/索敌、延迟统计、骑射与投射。

正常主菜单的原生窗口自动输入另通过八边形/血条/施工47项和冲击反馈21项；非人工鼠标试玩。原始记录与窗口截图存本机 output/perf-merge，不加入源码历史。

旧脚本 integration_order 的2项击退时序失败、mounted_run 的5项失败与 hills 访问错误，在未合并 main 的隔离副本复现，未计为通过。旧 facing_tactics 亦需保留基线记录，不能冒充新RTS入口的回归。

部分无窗口运行有退出资源引用警告。基线副本最初复用导入缓存仍缺 .import 映射，出现资源加载错误；随后重新导入再复测，早期基线运行不作为干净导入证明。最终合并副本二次导入无加载错误，原生窗口无脚本/资源加载错误。
