# 多排骑兵冲阵小样 · 2026-11-09

独立场景：`res://scenes/previews/cavalry_depth.tscn`。在 Godot 打开场景并按 F6，约 1.2 秒后自动冲锋；右上可暂停、继续、重新冲阵。正常主菜单、单排默认阵形、正式战斗平衡均未修改。未开发千人、攻城或经济玩法。

## 内容与边界

- 24 名轻骑兵（3×8）斜击 40 名步兵（4×10）。独立场景用既有逐兵移动、碰撞、伤害、盾墙、尸体与近战代码；没有按录像时间给受击者硬写位移或删除士兵。
- 草地复制自用户本机现有 `godot-game/assets/environments/iberia-grass-ground.png`，像素密度和原图不修改，哈希见 results.json。它此前不在 main 中，本次只在演示场景引用。
- 步兵横距 36、排距 38；骑兵横距 32、排距 60 地面单位。现有 64×64 八方向贴图、单位显示比例、敌我配色不改。未制作新动画或图集。草地的已有导入方式由 Godot 重建。
- 全部骑手同一次下达既有 C 命令，自身距离造成先后接触。正面盾墙、坚守长矛保留不同阻力。
- 已修复第一版左侧骑兵跑向空气：冲锋中心由 (1510,1620) 移到 (1610,1670)，逐骑检查初始冲锋线与敌阵相交。取消结束后无条件再前进 70 单位的命令；through/goal 结束后直接从当前位置重新选敌，受阻骑手留在接触处。这仍是独立小样的后续命令，不改变主工程 AI。
- 保持静音、无血条和无粒子，新增下面的命中表现层；没有新增倒地美术。

## 新增打击反馈（仅独立小样启用）

- 真实正伤害、明确受击槽位才记录反馈；同一士兵 0.20 秒内不重复启动闪白。未受击士兵不闪白、不抖动。
- 敌我双方统一使用纯白：重击白色轮廓持续8帧（约133ms），前4帧全白，随后分档衰减；普通命中6帧（约100ms），前3帧全白。白色图集保留原始alpha，不再只乘亮度。
- 接触双方的当前动作格停留5帧（约83ms），随后继续动作。只保留画面动作格，物理脚点、伤害、冷却、行军距离与整场模拟继续运行。
- 受击者局部抖动最大6个地面单位，短促偏转后收稳；脚下阴影保留在真实物理位置。没有拉伸人物。
- 镜头震动最大2个内部画布像素、约0.18秒，重击触发间隔至少0.45秒；HUD不抖。右上可独立关闭镜头震动，或关闭整套新反馈；暂停时关闭也立即归位。
