# 军团会战：肉鸽 + RTS 战斗原型

2026-11-13，当前开发分支 `yuho/rts-gameplay-expansion`。本次先同步最新 main 的美术和修复，再在个人分支替换经济 RTS。没有合并回 main。

## 试玩

用 Godot 4.x 打开 `godot-game/project.godot`，F5 → 主菜单「军团会战 · 布阵与交战」。也可单独运行 `scenes/legion_battle.tscn`。

我方枪兵、持盾步兵、骑兵、弓箭手各 35 人，共 140 人；敌方同四类各 30 人，共 120 人。进入后双方静止，点击「开战」后双方自动接敌，仍可实时指挥。默认方阵七人横列、五排纵深。

| 操作 | 效果 |
| --- | --- |
| 左键士兵、军团标签或底部卡片；数字 1–4 | 选择整个军团 |
| 左键拖框、Shift 点选 | 多选军团 |
| 战前右键地面 | 在部署区内移动军团，多选保留相对位置 |

| 战中右键地面 / 右键敌军 | 移动后坚守 / 集火敌方军团 |

## 本轮规则

每个士兵独立拥有生命、目标、攻击间隔和死亡状态，军团只统一属性、阵型和指令。人数显示、血条和战后损失均来自实际士兵；没有共享军团血池。

- 枪兵：方阵、楔形、环形、散阵。对骑兵增伤。
- 持盾步兵：方阵、龟甲、环形、楔形、散阵。基础护甲较高。
- 骑兵：方阵、楔形。持续行军后获得冲锋；侧后冲击增伤，对盾兵与弓兵有优势；冲锋暂时破坏敌方龟甲保护。
- 弓箭手：方阵、密集、散阵。普通箭矢具有飞行时间；箭雨为延迟范围攻击。密集阵降低普通攻击、增强箭雨，散阵降低范围伤害。
- 环形阵增加攻击和护甲并大幅减速，中央留空。部署检查实际士兵占地，可将另一军团布置在环内。
- 楔形阵提升冲锋，冲锋命中暂时降低敌军攻击、移动和攻击速度。
- 战中换阵需要 3 秒，期间不能攻击；完成后 10 秒冷却。战前换阵立即完成。暂停冻结换阵和技能计时。
- 撤退会实际向后方行军。安全脱战 6 秒且位于后方时恢复存活士兵的生命，不复活死者。
- 敌军全灭胜利，我方全灭失败。结算恢复幸存士兵的生命，保留伤亡统计；当前重试为重新测试，不是肉鸽下一场。

伤害为 `max(0, 基础攻击 × (1 + 增伤之和) × (1 - 减伤之和) - 对应基础护甲 × (1 + 护甲增益之和))`。近战/远程分别取护甲；相同种类的增益相加。设计图示例得到 2.8 伤害。

未指定的数值均为首版可调参数，不是最终平衡。兵种数据在 `data/balance/legion_battle.json`，阵型效果在 `scripts/legion/formations.gd`。地图复用现有伊比利亚草地/林缘资源和已批准的八方向兵种动画；中央为交锋空地，边缘林带不可进入，上方岩石有碰撞。

## 本轮清理与边界

已删除旧 `scripts/strategy/` 的采集、建造、生产、资源经济、城镇升级、迷雾/探索、蛮族据点等运行模块，移除旧经济配置以及依赖这些模块的失效测试。主菜单会战不再加载上述系统。现有美术资源、音效、主菜单原图和独立旧远征所需的共享战斗代码保留。

本轮不实现成长树、商店、战利品、路线、剧情、祭献、招募/扩编、精锐军团和跨战斗存档。旧远征入口仍为历史玩法，没有接入新的肉鸽循环。

## 验证

Linux Godot 4.6.3：

```sh
godot --headless --path godot-game --script res://tests/legion/test_battle.gd
godot --headless --path godot-game --script res://tests/legion/test_scene.gd
godot --path godot-game --script res://tests/legion/test_scene.gd
```

规则测试覆盖出生位置、部署限制、环内布兵、独立伤亡、伤害公式、换阵禁攻/时间/冷却、箭雨射程/冷却/实际伤害、撤退恢复和自然终局。场景测试覆盖正常菜单入口、按钮、暂停、结算、重试、退出和再次进入。原生窗口另用实际鼠标验证选队、换阵、环内布兵、开战和暂停。

运行证据写入本机 `output/legion-battle/`，不将截图或构建产物加入源码历史。规则和场景检查通过；没有完成 Windows 实机验证、长线平衡或跨局玩法。当前交付为 Godot 源工程，没有重新导出 Windows EXE。

最终检查：新规则 300 项、正常菜单至结算的场景检查 18 项均通过；场景检查也在原生窗口运行并保存部署/交战/结算截图。默认自动战斗自然在 23.63 模拟秒获胜，剩余92人；这只是固定首版配置，不代表完整平衡。主菜单键鼠回归94项通过，但旧测试退出仍有资源引用告警。另运行历史山口袭击回归，出现4个旧版岩石穿越失败；在改造前 `da50228` 的独立代码副本重跑同样4项失败，未将它们计为通过。本轮新战斗的规则/场景日志没有脚本错误或资源泄漏警告，原生软件渲染环境仅提示不支持调整V-Sync；未据此声称Windows或硬件帧率验收。

最终实际鼠标/键盘试玩还验证了框选两军团并整体移动、弓兵密集阵、暂停中指定箭雨和盾兵撤退；恢复后箭雨落下、盾兵向后方行军，约25秒自然胜利，剩余78人。该局包含人工操作，与默认自动战斗及场景测试的兵力结果分开记录。
