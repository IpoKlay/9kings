# 军团会战：肉鸽 + RTS 战斗原型

2026-11-13，当前开发分支 `yuho/rts-gameplay-expansion`。本次先同步最新 main 的美术和修复，再在个人分支替换经济 RTS。没有合并回 main。

## 试玩

用 Godot 4.x 打开 `godot-game/project.godot`，F5 → 主菜单「军团会战 · 布阵与交战」。也可单独运行 `scenes/legion_battle.tscn`。

我方枪兵、持盾步兵、骑兵、弓箭手各 35 人，共 140 人；敌方同四类各 30 人，共 120 人。进入后双方静止，点击「开战」后双方自动接敌，仍可实时指挥。默认方阵七人横列、五排纵深。

## 本轮规则

每个士兵独立拥有生命、目标、攻击间隔和死亡状态，军团只统一属性、阵型和指令。人数显示、血条和战后损失均来自实际士兵；没有共享军团血池。

- 枪兵：方阵、组合环阵、散阵。近战射程 68；普通攻击对骑兵增伤。
- 持盾步兵：方阵、龟甲、组合环阵、散阵。近战射程 32；基础护甲较高。
- 步兵和弓兵保持当前阵位，按实际距离寻找可攻击的敌人。后排射程不够便等待；前方出现空位时，由最近的空闲后排逐级向前补位。已经能攻击敌人的士兵继续攻击，即使敌人在侧后方也不会被强制调去填前排。死亡不再重排全军。环阵没有固定前排，仅在补位能够接敌时补位，避免空位在全环循环。
- 骑兵：方阵、楔形。骑兵普通攻击自由追击附近敌人，不使用步兵补位规则，也不会自动发动冲锋。强制移动时全员停止攻击并向阵位行军；到齐后恢复默认方阵。移动攻击则允许途中普通追击，清除附近敌人后返回原目标，到齐后同样恢复方阵。
- 弓箭手：方阵、密集、散阵，可作为组合内环。普通箭矢具有飞行时间；箭雨为延迟范围攻击。密集阵降低普通攻击、增强箭雨，散阵降低范围伤害。
- 楔形仅限骑兵、仅在战前设置，战斗中不能通过阵型按钮手动切入或切出；可以 G 解散进入自由攻击，或通过普通移动到位后自动恢复方阵。楔形不再提高普通攻击；每名骑兵首次主动冲锋命中的敌人攻速降低 50%、移动速度降低 100%，持续 4 秒。后续冷却完成的冲锋不重复这项首次削弱。
- 战中其他换阵需要 3 秒，期间不能攻击；完成后 10 秒冷却。战前换阵立即完成。暂停冻结换阵、冲锋冷却与状态计时。
- 撤退会实际向后方行军。安全脱战 6 秒且位于后方时恢复存活士兵的生命，不复活死者。
- 敌军全灭胜利，我方全灭失败。结算恢复幸存士兵的生命，保留伤亡统计；当前重试为重新测试，不是肉鸽下一场。

### 自由攻击与重新成阵

所有军团战斗中均可按 G 或点击「自由攻击」。取消当前阵型、换阵进度和组合关联，不改变士兵当前位置；所有士兵各自寻找最近敌人，进入自身射程后攻击。没有阵型的护甲/攻击/攻速/移速加成，也没有相应减益。兵种基础属性与已受敌人施加的临时状态仍有效。骑兵在此模式也不会自动冲锋。

自由攻击时，其他阵型按钮禁用。下达移动或移动攻击（撤退同样会先收队）后，先集结为默认方阵；真正回到阵位后，才解锁其他允许的阵型。集结期间不攻击，之后按所选移动指令执行。刚解除的两支同心军团一起移动时，目标处分开列阵，避免再次重叠。地图边缘的集结中心会留出完整方阵空间。

### 骑兵主动冲锋

选中骑兵，Q 后左键指定终点。战前可预设，点击开战后执行；H 可取消战前预令。战中同样通过 Q/按钮主动发动。冲锋不会根据附近敌人自行触发或改变方向。军团先按当前阵型集结、转向，然后保持所有存活成员的相对阵位一起前进。目标标记对应**最靠近阵型中心的那名士兵**的最终位置，而非军团几何中心；即使楔形中心没有阵位，也会准确对齐所选中心士兵。

每个军团独立计算 20 秒冷却，从真正开始冲锋计时，预设和整队不消耗冷却。路径必须容得下整个阵型，不能穿过岩石或地图边界。冲锋持续到目标，不再使用旧的 2.4 秒超时。移动、坚守或自由攻击可以取消当前冲锋，已经消耗的冷却不会退还。

冲锋对每名骑兵路径半径 20 内接触到的全部敌人造成小范围伤害；同一骑兵在同次冲锋中不会重复伤害同一敌人，不同骑兵的命中独立计算。伤害统一为 `基础攻击 × 1/3`（当前骑兵攻击18，即每次6伤害），直接扣除生命；不计护甲、普通增伤、旧冲锋增伤列表、命中顺序或兵种倍率。**旧的四人上限、2/1/0.5/0.25 递减、楔形首击例外和枪兵伤害例外全部删除。**

冲锋骑兵被枪兵实际攻击命中时，整团立即停止冲锋，以避免剩余骑兵继续前进导致队形撕裂；仅接触尚未攻击的枪兵，不再触发旧的接触即停逻辑。普通攻击恢复后继续按骑兵原本的方式接敌。

保留不属于旧伤害算法的状态效果：首次楔形冲锋命中使敌人攻速降低50%、移动速度降低100%，持续4秒；命中盾兵使其军团破阵4秒，阵位和减益保留，正面阵型效果暂时失效。

### 组合环阵

仅战前可创建组合。选中枪兵或持盾步兵作为外环，点击「组合环阵」，出现“选择组合的军团”，高亮尚未组合的枪兵和弓箭手；点击战场士兵、军团卡片或对应编号选定内环。组合时检查双方整套位置，空间不足则保留原部署。

外环包裹内环，内环与对应外环士兵相隔 26。两支军团统一中心和移动指令，以较慢一方的速度移动；移动不旋转圆环的阵位。外环接触敌人后两团一起停下，在接触面按每名士兵实际射程交战，其他士兵射程不足便不攻击。内环弓手可随阵行进时射击，远程射击本身不让整个环阵提前停止；敌人被清除后继续原移动攻击指令。双方护甲 +60%，外环攻击 −25%，内环攻速 +30%。选中任一半或其编号都会选中整对。战前点击「解除组合」恢复组合前部署（原位置被占用时提示先移开）；战中点击则在当前位置解开两团，并让双方进入自由攻击，不会传送或恢复到战前位置。其中一团全灭后，另一团保留现有站位但失去组合增益。

普通攻击伤害为 `max(0, 基础攻击 × (1 + 增伤之和) × (1 - 减伤之和) - 对应基础护甲 × (1 + 护甲增益之和))`。近战/远程分别取护甲；相同种类的增益相加。设计图示例得到 2.8 伤害。

未指定的数值均为首版可调参数，不是最终平衡。射程、冲锋冷却、扫掠范围、4 秒削弱/破阵等数据在 `data/balance/legion_battle.json`（4 秒持续、60% 护甲和25%攻击减益是未指定部分的暂定值），阵型效果在 `scripts/legion/formations.gd`。地图复用现有伊比利亚草地/林缘资源和已批准的八方向兵种动画；中央为交锋空地，边缘林带不可进入，上方岩石有碰撞。

## 本轮清理与边界

已删除旧 `scripts/strategy/` 的采集、建造、生产、资源经济、城镇升级、迷雾/探索、蛮族据点等运行模块，移除旧经济配置以及依赖这些模块的失效测试。主菜单会战不再加载上述系统。现有美术资源、音效、主菜单原图和独立旧远征所需的共享战斗代码保留。

本轮不实现成长树、商店、战利品、路线、剧情、祭献、招募/扩编、精锐军团和跨战斗存档。旧远征入口仍为历史玩法，没有接入新的肉鸽循环。

## 验证

Linux Godot 4.6.3：

```sh
godot --headless --path godot-game --script res://tests/legion/test_battle.gd
godot --headless --path godot-game --script res://tests/legion/test_tactics.gd
godot --headless --path godot-game --script res://tests/legion/test_scene.gd
godot --path godot-game --script res://tests/legion/test_scene.gd
```

规则测试覆盖出生与部署、独立伤亡、普通伤害公式、换阵、箭雨、撤退恢复和自然终局；专项测试覆盖编队、射程补位、受包围时优先攻击、强制移动禁攻、移动攻击、环阵接触停步/射程/恢复前进、战中解环、所有兵种自由攻击/重新成阵、地图边缘集结、主动冲锋/预令/取消/冷却、相对队形、中心士兵终点、超过四个目标的统一路径伤害，以及实际枪兵攻击中断冲锋。

场景检查从正常菜单进入，验证真实键盘输入、组合按钮/候选高亮、战中解环、G 自由攻击、Q 主动冲锋与预令、移动瞄准、暂停、自然结算、重试和再次进入。相同场景检查在原生窗口运行并截图。运行证据在本机 `output/legion-v3-*.log` 和 `output/legion-battle/`，不提交截图或构建产物。

当前交付仍为 Godot 源工程；未重新导出 Windows EXE，未做 Windows 实机或长期平衡验收。Linux 原生软件渲染仅报告驱动无法调整 V-Sync；编辑器现有 Godot AI 插件要求 4.7，在验证用 4.6.3 下不激活，不影响游戏运行。此前历史山口袭击的 4 项岩石穿越失败已在改造前版本复现，属于旧远征路径，本次未更改。

本轮验证：基础规则300项、战术专项209项、场景47项通过；场景47项亦在Linux原生窗口通过。默认无主动冲锋的战斗在52.03模拟秒自然结束，我方剩67人。实际键鼠试玩另验证战前楔形冲锋预令、环阵移动攻击正面接敌、战中解除环阵、G自由攻击、盾兵M重新成阵；该局约43秒自然胜利，剩87人。两局指令不同，不用来宣称平衡结论。最后增加了边缘集结回归并修正从地图边缘寻路时无法恢复默认方阵的问题。
