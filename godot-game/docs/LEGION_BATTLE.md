# 军团会战：肉鸽 + RTS 战斗原型

2026-11-13，当前开发分支 `yuho/rts-gameplay-expansion`。本次先同步最新 main 的美术和修复，再在个人分支替换经济 RTS。没有合并回 main。

## 试玩

用 Godot 4.x 打开 `godot-game/project.godot`，F5 → 主菜单「军团会战 · 布阵与交战」。也可单独运行 `scenes/legion_battle.tscn`。

我方枪兵、持盾步兵、骑兵、弓箭手各 35 人，共 140 人；敌方同四类各 30 人，共 120 人。进入后双方静止，点击「开战」后双方自动接敌，仍可实时指挥。默认方阵七人横列、五排纵深。

| 操作 | 效果 |
| --- | --- |
| 左键士兵、军团标签或底部卡片；数字 1–7（含小键盘） | 选择整个军团 |
| Ctrl + 数字 1–7 | 将当前选择绑定到该编队；初始 1–4 对应四个军团，5–7 留空，可绑定多个军团 |
| 左键拖框、Shift 点选 | 多选军团；组合环阵总是一起选择 |
| 战前右键地面 | 在部署区内移动军团，多选保留相对位置 |
| 战前右键拖动 | 按下位置为军团中心，拖动方向为朝向 |
| 底部阵型按钮 | 选择所选军团共同支持的阵型；悬停查看效果 |
| 开战 / Enter | 开始战斗 |
| 战中右键地面，或 M 后左键 | 强制移动，到齐后坚守；途中禁止普通攻击、冲锋和箭雨 |
| A 后左键目标位置 | 移动攻击：遇敌交战，清除附近敌人后继续到目标位置 |
| 战中右键敌军 | 集火敌方军团 |
| H / R | 坚守 / 撤退休整 |
| V 后左键落点 | 弓兵箭雨；右键取消瞄准 |
| 空格 | 暂停或继续，可在暂停时下令 |
| 中键拖动、方向键、滚轮、F | 平移、缩放、恢复总览 |
| Esc | 清空选择和瞄准，不撤销已发军令 |
| 重置布阵 / 结算中的重新布阵 | 重开同一配置的战斗 |

## 本轮规则

每个士兵独立拥有生命、目标、攻击间隔和死亡状态，军团只统一属性、阵型和指令。人数显示、血条和战后损失均来自实际士兵；没有共享军团血池。

- 枪兵：方阵、组合环阵、散阵。近战射程 68；普通攻击对骑兵增伤。
- 持盾步兵：方阵、龟甲、组合环阵、散阵。近战射程 32；基础护甲较高。
- 步兵和弓兵保持当前阵位，按实际距离寻找可攻击的敌人。后排射程不够便等待；前方出现空位时，由最近的空闲后排逐级向前补位。已经能攻击敌人的士兵继续攻击，即使敌人在侧后方也不会被强制调去填前排。死亡不再重排全军。环阵没有固定前排，仅在补位能够接敌时补位，避免空位在全环循环。
- 骑兵：方阵、楔形。骑兵自由追击附近敌人，不使用步兵补位规则。强制移动时全员停止攻击并向阵位行军；到齐后恢复默认方阵。移动攻击则允许途中追击、冲锋，清除附近敌人后返回原目标，到齐后同样恢复方阵。
- 弓箭手：方阵、密集、散阵，可作为组合内环。普通箭矢具有飞行时间；箭雨为延迟范围攻击。密集阵降低普通攻击、增强箭雨，散阵降低范围伤害。
- 楔形仅限骑兵、仅在战前设置，战斗中不能手动切入或切出。完成移动后的自动恢复方阵不受此限制。楔形不再提高普通攻击；每名骑兵首次冲锋命中的敌人攻速降低 50%、移动速度降低 100%，持续 4 秒。后续冷却完成的冲锋不重复这项首次削弱。
- 战中其他换阵需要 3 秒，期间不能攻击；完成后 10 秒冷却。战前换阵立即完成。暂停冻结换阵、冲锋冷却与状态计时。
- 撤退会实际向后方行军。安全脱战 6 秒且位于后方时恢复存活士兵的生命，不复活死者。
- 敌军全灭胜利，我方全灭失败。结算恢复幸存士兵的生命，保留伤亡统计；当前重试为重新测试，不是肉鸽下一场。

### 骑兵冲锋

每名骑兵独立计算 20 秒冷却，从发动时计时。冲锋朝初始目标方向穿入阵中，以半径 20 的扫掠接触区命中实际士兵；同次最多伤害四个不同敌人，同一士兵不重复受该骑兵的冲锋伤害。碰到枪兵或已伤害四人立即停止；无接触时冲锋最多持续 2.4 秒，撞到地形也会停止。

| 冲锋 | 第一人 | 第二人 | 第三人 | 第四人 |
| --- | --- | --- | --- | --- |
| 默认方阵 | 2× | 1× | 0.5× | 0.25× |
| 楔形阵 | 1× | 1× | 0.5× | 0.25× |

枪兵无论命中顺序均只受 1×，并阻断本次冲锋。每次接触范围内的士兵也计入四人上限，不额外产生无限溅射目标。伤害为 `基础攻击 × 本次倍数 × (1 + 冲锋增伤之和)`，属于真实伤害，忽略护甲，不读取普通攻击增伤或普通攻击兵种克制。

命中持盾步兵后，该军团暂时破阵 4 秒：保留阵型、阵位以及全部负面效果，暂时移除阵型正面效果。龟甲仍保留 0.38 倍移速，失去额外护甲；组合外环仍保留攻击降低，失去额外护甲。

### 组合环阵

仅战前可组合或解除。选中枪兵或持盾步兵作为外环，点击「组合环阵」，出现“选择组合的军团”，高亮尚未组合的枪兵和弓箭手；点击战场士兵、军团卡片或对应编号选定内环。组合时检查双方整套位置，空间不足则保留原部署。

外环包裹内环，内环与对应外环士兵相隔 26。两支军团统一中心、朝向和移动指令，以较慢一方的速度移动。双方护甲 +60%，外环攻击 −25%，内环攻速 +30%。选中任一半或其编号都会选中整对。再次点击「解除组合」恢复组合前部署（原位置被占用时提示先移开）。其中一团全灭后，另一团保留现有站位但失去组合增益。

伤害为 `max(0, 基础攻击 × (1 + 增伤之和) × (1 - 减伤之和) - 对应基础护甲 × (1 + 护甲增益之和))`。近战/远程分别取护甲；相同种类的增益相加。设计图示例得到 2.8 伤害。

未指定的数值均为首版可调参数，不是最终平衡。射程、冲锋冷却、扫掠范围、4 秒削弱/破阵等数据在 `data/balance/legion_battle.json`（4 秒持续、60% 护甲和25%攻击减益是未指定部分的暂定值），阵型效果在 `scripts/legion/formations.gd`。地图复用现有伊比利亚草地/林缘资源和已批准的八方向兵种动画；中央为交锋空地，边缘林带不可进入，上方岩石有碰撞。

## 本轮清理与边界

已删除旧 `scripts/strategy/` 的采集、建造、生产、资源经济、城镇升级、迷雾/探索、蛮族据点等运行模块，移除旧经济配置以及依赖这些模块的失效测试。主菜单会战不再加载上述系统。现有美术资源、音效、主菜单原图和独立旧远征所需的共享战斗代码保留。

本轮不实现成长树、商店、战利品、路线、剧情、祭献、招募/扩编、精锐军团和跨战斗存档。旧远征入口仍为历史玩法，没有接入新的肉鸽循环。

## 验证

Linux Godot 4.6.3：

```sh
godot --headless --path godot-game --script res://tests/legion/test_battle.gd
godot --headless --path godot-game --script res://tests/legion/test_tactics.gd
godot --headless --path godot-game --script res://tests/legion/test_scene.gd
godot --path godot-game --script res://tests/legion/test_scene.gd
```

规则测试覆盖出生与部署、独立伤亡、普通伤害公式、换阵、箭雨、撤退恢复和自然终局；专项测试覆盖 1–7 编队、射程差异、空闲后排逐级补位、受包围时优先攻击、强制移动禁攻、移动攻击恢复原目标、骑兵到齐后恢复方阵、四次真实伤害、枪兵阻断、20 秒冷却、首次楔形削弱、破阵保留减益，以及组合环阵联动和原子部署。

场景检查从正常菜单进入，验证真实键盘输入、组合按钮/候选高亮、移动瞄准、暂停、自然结算、重试和再次进入。相同场景检查在原生窗口运行并截图。运行证据在本机 `output/legion-v2-*.log` 和 `output/legion-battle/`，不提交截图或构建产物。

当前交付仍为 Godot 源工程；未重新导出 Windows EXE，未做 Windows 实机或长期平衡验收。Linux 原生软件渲染仅报告驱动无法调整 V-Sync；编辑器现有 Godot AI 插件要求 4.7，在验证用 4.6.3 下不激活，不影响游戏运行。此前历史山口袭击的 4 项岩石穿越失败已在改造前版本复现，属于旧远征路径，本次未更改。

本轮结果：基础规则 300 项、战术专项 131 项、菜单至结算场景 36 项全部通过；36 项场景检查也在原生窗口通过。默认配置自然在 54.80 模拟秒结束，我方剩余 70 人。另一次实际键鼠试玩验证盾兵/弓兵组合、七号编队绑定召回、组合移动攻击、骑兵楔形强制移动及恢复方阵，随后在 71 秒左右自然胜利，剩余 76 人；两局配置与指令不同，不作为平衡结论。
