## 修改前已复现的差异

30/60/120 三个推进采样条件均为 14 次接触、0 骑越线；正常距离测试均返回 1，未放宽“至少一骑越线”的断言。三次冲锋结束记录完全一致，首次命中采样为 1.9333/1.9167/1.9167 秒，差异为渲染采样粒度。这是固定步规则诊断，不是实时 FPS 测试。

已有原作旧公开版观察（20260409，作者标为旧版）记录了显式 F 单排 Swordsmen 被 Light Cavalry 局部打开，有骑兵跨过原线再转近战。记录来源：公开页 https://bitrotgames.itch.io/sword-banner ，旧观察文件 `output/sword-banner-reference/original-braced/observations.json`；本次未重新运行原作，不能把旧记录冒充新实测。

当前实现对正面坚守盾兵累加阻力 0.72，阈值 0.7，随后最多再让步 14 单位便停止；原旧版规则摘记为每个不同受击者累计 0.12 减速、上限 0.65，冲锋按目标/时长/低速条件结束，未发现盾或矛专用强制拦停。该摘记来自旧公开包，不是新版 Steam 源码。仅有单人“盾停/矛停”测试通过，不能证明它与原作相符。

可见窗口重跑同样得到 14 次接触、0 骑越线，已检查截图。超距负对照为 2 次接触、0 骑越线，全部以 duration 结束，不能把这种停止归因为盾墙拦截。
